# dev-log 开发日志

本文件夹记录每日开发日志，文件名格式：`YYYY-MM-DD.md`。

## 规则

1. 每天一个文件，以当天日期命名（如 `2026-08-07.md`）。
2. 每次开发会话结束时更新当天日志。
3. 跨天继续工作：新建当天日志文件，并沿用上一日的"待办事项"。

## 模板

```markdown
# 2026-08-07 开发日志

## 完成事项
- [ ] 事项描述（附涉及文件）

## 待办事项
- [ ] 下一步要做的事

## 问题记录（可选）
- 遇到的问题
- 解决方案
```

## 查看方式

按文件名倒序查看最新日志，了解项目当前进度与待办。
