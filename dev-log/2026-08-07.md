## 问题记录

- Yarn→Mojang 脚本替换误伤：`backKey` 规则误伤 `feedbackKey`（→feedkeyDown）；`Text` FQN 前缀误伤 `TextColor`（→ComponentColor）；`PlayerEntity` 误伤 Mixin 类名；已逐一修复
- Mojang 1.21.11 与旧版 API 差异：`ResourceKey.location()` 已改名为 `identifier()`、`OptionInstance.getValue()` 改名为 `get()`、`KeyMapping.setPressed/isPressed` 改名为 `setDown/isDown`、title 处理包方法为 `setTitleText/setSubtitleText`（非 handle 前缀）
