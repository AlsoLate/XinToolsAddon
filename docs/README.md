# docs 文档索引

项目标准文档体系。开发前请先阅读：

| 文件 | 内容 | 何时阅读 |
|---|---|---|
| [requirements.md](requirements.md) | 已确认的功能需求（含验收标准） | 开发任何功能前 |
| [technical.md](technical.md) | 技术栈、架构、实现方案 | 开发与排错时 |
| [design.md](design.md) | 代码/文档命名与风格规范 | 写代码时 |
| [process.md](process.md) | 标准工作流程与执行步骤 | 每个工作会话开始时 |
| [roadmap.md](roadmap.md) | 分阶段开发计划 | 规划下一步时 |

其他目录：

- `dev-log/`（项目根目录）：每日开发日志，记录完成事项与待办事项
- `CLAUDE.md`（项目根目录）：AI 工作指引，含各标准文件路径
